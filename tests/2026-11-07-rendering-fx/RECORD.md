# 渲染中特效 + 状态卡死修复 — 2026-11-07（固件 v6）

## 需求
「有时已经生成完了，还显示生成中还在计时。生成中改成渲染中，不同状态不同颜色，
lvgl 能做的炫彩效果都试试。」

## 卡死 bug（先修的）
`fetchQueue` 清 running 的条件是 `running==0 && running && !connected`——WS 连着时
/queue 兜底被禁用。而 execution_success 事件可能因 WS 掉线重连丢失，running 永久
true，计时 millis()-start_ms 一直走。修复：/queue 队列空即清，不论 WS。
上机验证：提交 9s 渲染任务，结束后状态字立即回「空闲」、计时归 00:00。

## 改名与配色
- 生成中 → 渲染中（GENERATING → RENDERING），日志头「生成」→「渲染」
- 空闲=绿 / 排队中=橙 / 连接中=琥珀 / 离线·无网络=红 / 渲染中=动态霓虹

## LVGL 8 特效（66ms 定时器，≈15fps）
| CSS 概念 | LVGL 等价实现 | 实测 |
|---|---|---|
| gradient text | lv_label recolor 逐字 #RRGGBB，色相每字 +28°，三角波亮度呼吸 | ✓ 三字三色流动 |
| box-shadow pulse | 状态字底牌（圆角 8 + card 底色）+ shadow_width 2..18px 呼吸 | ✓ 光晕可见 |
| aurora 渐变 | 进度条指示条 HSV 色相循环（3.2s/圈） | ✓ 红→金→粉流动 |
| 多元素波次 | 多主机色相错开 137°（金角），各卡各自流光 | ✓ win 粉/halo 金 |
| 做不到的 | backdrop-filter、conic-gradient、逐字形（glyph 级）发光 | — |

实现约束：每帧只改样式值，失效区域仅状态字+进度条；1s 轮询刷新在渲染中时让位
特效层（fxActive 门控）避免样式打架。ui_max_ms 与 v5 持平（≈200ms，无恶化）。
